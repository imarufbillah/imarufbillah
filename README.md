## Projects

### RecipeHub — Full-Stack Recipe Platform
> Bangladeshi and global recipe sharing with user submissions, editorial design, and Stripe integration.

`Next.js` · `Express.js` · `MongoDB` · `BetterAuth` · `Stripe` · `imgbb`

- JWT-secured API with role-based access and session management
- Editorial-luxury design system (Bodoni Moda · Burnt Sienna palette)
- Image upload pipeline via imgbb with raw MongoDB driver (no Mongoose)

---

### Seekcruitr — Job Portal
> Three-role job platform for seekers, recruiters, and admins with a dark professional UI.

`Next.js` · `Express.js` · `MongoDB` · `BetterAuth`

- Full MongoDB schema design across roles, jobs, and applications
- OKLCH design token system with deep navy and electric teal palette
- Separate frontend/backend repos with centralized API client
